# Manual Run

To manually run the project, open your terminal and execute the following commands:

```bash
cd cclms_react
npm i
npm run dev
```

### Steps

1. Navigate to the project directory:

   ```bash
   cd cclms_react
   ```

2. Install the project dependencies:

   ```bash
   npm i
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

The terminal will provide a local URL where you can access the application.
